教學安排建議

  • 前半段先建立最小 Python 能力，避免語法過多造成負擔。
  • 中段重點放在 Raspberry Pi GPIO 與感測器操作。
  • 後半段導入 HTTP / MQTT，讓學生理解裝置如何與外部系統溝通。
  • 若時間允許，再加入 Flask 與簡單 dashboard，形成完整專題雛形。

建議 Python 套件

這些套件足以支撐大部分 Raspberry Pi 物聯網入門實作。

gpiozero

適合初學者的 GPIO 控制套件，語法相對直觀，適合入門教學。

RPi.GPIO

較低階的 GPIO 控制方式，適合說明底層控制觀念。

requests

用於 HTTP 與 REST API 溝通，適合上傳或取得 IoT 資料。

paho-mqtt

常見 MQTT 套件，可用於裝置與 broker 之間的訊息交換。

Flask

用於建立簡單 Web API 或儀表板，適合課程延伸專題。

pandas（選修）

可用於後續資料分析、整理與視覺化，屬於延伸能力。

本課程 Python 學習目標

完成這份學習大綱後，學生應能具備以下實作能力。
  • 使用 Python 控制 Raspberry Pi GPIO。
  • 讀取與處理基本感測器資料。
  • 將資料儲存為文字檔、CSV 或 JSON。
  • 透過 HTTP 或 MQTT 傳送資料。
  • 建立簡單的 IoT 應用系統。
